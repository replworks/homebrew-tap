⚡ 저장소 등록 및 설치 방법

터미널에서 아래 명령어를 실행하여 저장소를 등록하고 패키지를 설치하세요.

RECOMMENDED 한 줄로 바로 설치 (tap 등록 불필요) 
brew install --cask replworks/tap/<패키지 이름>

* tap을 미리 등록하지 않아도 replworks/tap/<이름> 형식으로 즉시 설치할 수 있습니다.

또는 단계별로 직접 실행하기

1 Tap 저장소 등록(처음 한 번만) 
brew tap replworks/tap
2 패키지 설치 
brew install --cask <패키지 이름>
3 패키지 업데이트, 삭제 및 저장소 해제
업데이트 
brew upgrade --cask <이름>
삭제 
brew uninstall --cask <이름>
저장소 해제 
brew untap replworks/tap
💡
Linux (Debian / Ubuntu) 사용자이신가요? Cask는 macOS 전용입니다. Debian 및 Ubuntu 환경에서는 APT 저장소(apt.repl.net)를 통해 동일한 패키지를 설치하실 수 있습니다.

📦 배포 중인 Cask 패키지

이 저장소의 Casks/ 디렉토리에서 자동 관리되는 최신 패키지 목록입니다.

배포된 패키지 메타데이터는 GitHub Actions 배포 주기에 맞춰 자동으로 갱신됩니다.
ℹ️

새 저장소(패키지) 추가하는 법

이 저장소는 직접 수정할 필요가 없습니다. 추가할 프로젝트 쪽에서 아래 3가지만 설정하면 첫 릴리스 시 Casks/에 자동 등록됩니다. 추가할 프로젝트를 replworks/repo라고 하자.

1. .goreleaser.yaml에 homebrew_casks 추가 
homebrew_casks:
  - repository:
      owner: replworks
      name: homebrew-tap
      token: "{{ .Env.HOMEBREW_TAP_GITHUB_TOKEN }}"

    homepage: "https://github.com/replworks/{{ .ProjectName }}"
    description: "<설명>"
    custom_block: |
      on_macos do
        postflight_steps do
          run "/usr/bin/xattr", args: ["-dr", "com.apple.quarantine", "{{ "{{" }}staged_path{{ "}}" }}/<바이너리 이름>"]
        end
      end
  • homepage와 description은 랜딩 페이지 카드에 그대로 표출됩니다.
  • custom_block은 서명 안 된 바이너리가 Gatekeeper에 막히지 않게 quarantine 속성을 지웁니다.
  • builds에 darwin(amd64, arm64)이 들어 있어야 합니다.
  • 로컬 확인: goreleaser release --snapshot --clean 으로 dist/ 에 cask 확인
2. HOMEBREW_TAP_TOKEN 시크릿 등록

organization 시크릿으로 등록해뒀으면 접근 권한만 열어주면 됩니다.

• fine-grained PAT • Repository access: replworks/homebrew-tap만 • Permissions: Contents → Read and write

3. release.yml의 goreleaser 스텝에 환경변수 추가 
- uses: goreleaser/goreleaser-action@v7
  with:
    version: latest
    args: release --clean
  env:
    GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
    HOMEBREW_TAP_GITHUB_TOKEN: ${{ secrets.HOMEBREW_TAP_TOKEN }}
⚠️ 참고: Casks/<이름>.rb는 직접 만들지 않습니다. goreleaser가 릴리스할 때마다 덮어쓰기 때문에 수동으로 고친 내용은 사라집니다. 설정을 변경하려면 프로젝트의 .goreleaser.yaml을 고치세요.
